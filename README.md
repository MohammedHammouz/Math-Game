# Math-Game
Math-Game project includes procedures,functions,structures,and enums the idea of this project is ,when some one want do a quiz the compiler will ask how many questions want answer,then will choose the level of the exam,then will choose operation type 
#
The Math-Game project is a quiz game that includes procedures, functions, structures, and enums. The project allows users to take a quiz by specifying the number of questions they want to answer. The quiz includes questions of varying difficulty levels and different types of mathematical operations (addition, subtraction, multiplication, division, and mixed). The game evaluates the user's answers and provides feedback on their performance.
